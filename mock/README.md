# RaiseTimeline 静的モック

[要件定義書](../docs/01_requirements.md)・[機能一覧](../docs/02_features.md)・[画面設計](../docs/03_screens.md)に基づいて、HTML / CSS / JavaScript だけで作ったプロトタイプです。実装（React + Spring Boot）に入る前に、画面の流れと操作感を確かめるために使います。

## 開き方

ビルドもサーバーも不要です。`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。

```bash
# Git Bash（リポジトリのルートで）
start mock/index.html
```

エクスプローラーで `mock/index.html` をダブルクリックしても開けます。

## 盛り込んだ機能

機能一覧の F-01〜F-23 と、画面 SC-01〜SC-07・画像ビューアーをすべて再現しています。入力制約とエラーの文言は機能別要件書に合わせています。

| 画面 | URL（モック） | 主な機能 |
| --- | --- | --- |
| SC-01 ログイン | `#/login` | F-02 |
| SC-02 新規登録 | `#/signup` | F-01 |
| SC-03 タイムライン | `#/`、`#/?tab=following` | F-05〜F-08, F-10, F-14, F-15, F-17, F-21 |
| SC-04 投稿詳細 | `#/posts/:id` | F-09〜F-15, F-17 |
| SC-05 プロフィール | `#/users/:username` | F-16, F-19, F-20 |
| SC-06 プロフィール編集 | `#/settings/profile` | F-18 |
| SC-07 ユーザー検索 | `#/search`、`#/search?q=<検索語>` | F-19, F-22, F-23 |

共通ヘッダー（ログアウト F-03）、未ログイン時のアクセス制御（F-04）も動きます。

ユーザーのアイコンは、プロフィール編集（SC-06）の [画像を選択] で設定し、[アイコンを削除] で外せます。どちらも [保存する] を押したときに反映されます。未設定のユーザーは、表示名の頭文字を色付きの丸で表示します。初期データでは hanako・han・Hana_dev・sakura・jiro・sora にアイコンを設定してあります。

## 本番の実装との違い

| 項目 | モック | 本番（予定） |
| --- | --- | --- |
| URL | ハッシュ（`#/posts/1`） | パス（`/posts/1`） |
| データの保存先 | ブラウザの localStorage（このブラウザだけ） | PostgreSQL |
| 画像 | 投稿画像は長辺 1200px、アイコンは中央を正方形に切り抜いて 400px の JPEG にし、localStorage に保存 | S3（開発時はローカルのディスク） |
| パスワード | 平文のまま localStorage に保存（モックなので） | BCrypt でハッシュ化 |
| 権限の確認 | 画面側だけ | サーバー側でも確認 |
| ログイン状態 | localStorage（期限なし） | セッション Cookie（14 日間） |

- データは画面下部の「データをリセット」で初期状態に戻せます。
- 画像をたくさん投稿すると localStorage の容量（ブラウザごとに約 5MB）を超えることがあります。そのときはメッセージが出て、その変更は再読み込みで消えます。
- 同じブラウザの別タブで別のユーザーとしてログインすると、ログイン状態は共有されます（localStorage が 1 つのため）。2 人同時に試すときは、Chrome と Edge のように別のブラウザを使ってください。
