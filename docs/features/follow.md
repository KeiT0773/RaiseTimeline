## 2. 概要

他のユーザーをフォロー・解除し、フォロー数・フォロワー数を表示する機能。フォローしたユーザーの投稿は、タイムラインの「フォロー中」タブ（[timeline.md](timeline.md) F-21）に表示される。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-19 | フォロー / 解除 | SC-05, SC-07 |
| F-20 | フォロー数・フォロワー数表示 | SC-05 |

### 2.1 フォローする相手の見つけ方

フォローする相手を見つけてフォローするまでの経路は、次の 2 つとする。

| 経路 | 流れ | フォローする場所 |
| --- | --- | --- |
| 1. ユーザー検索から | 共通ヘッダーの「🔍 ユーザーを探す」→ ユーザー検索画面（SC-07）で @ユーザー名や表示名を入れて検索する（[user-search.md](user-search.md) F-22）。検索欄が空ならおすすめユーザーが表示される（F-23） | 結果の行の [フォローする]（その場でフォローできる）。行をクリックしてプロフィール（SC-05）へ移り、そこでフォローしてもよい |
| 2. 投稿・コメントから | 次の場所で、表示名・@ユーザー名をクリックする → そのユーザーのプロフィール（SC-05）が開く<br/>・タイムライン（SC-03）の投稿者<br/>・投稿詳細（SC-04）の投稿者と、コメントした人<br/>・プロフィール（SC-05）の投稿一覧の投稿者 | プロフィール（SC-05）の [フォローする] |

- 経路 2 で、クリックで反応する範囲はアイコンと名前の部分だけにする。投稿カードの本文のクリック（投稿詳細へ移る）とぶつからないようにする（[画面設計](../03_screens.md) 4.）
- 自分の名前をクリックしたときは自分のプロフィールが開く。フォローボタンは出さず、[プロフィールを編集] を出す

## 3. 業務ルール

- フォローできるのは他のユーザーだけ（**自分自身はフォローできない**）。
- フォローは相手の承認なしで、すぐに成立する（鍵アカウントは無い）。相手への通知も無い。
- 同じユーザーを 2 回フォローできない（画面・サーバー・DB の一意制約の 3 段で防ぐ）。
- フォローを解除するときに確認ダイアログは出さない（すぐにフォローし直せるため）。
- フォロー中・フォロワーの一覧画面は作らない（件数の表示だけ）。
- ユーザーが退会した場合（将来の機能）は、そのユーザーのフォロー関係も消える（DB の `ON DELETE CASCADE`）。

## 4. 機能詳細

### F-19 フォロー / 解除

- フォローボタンを表示する場所：他人のプロフィール（SC-05）、ユーザー検索の結果とおすすめユーザー（SC-07）
- ボタンの状態
  - 未フォロー：[フォローする]（塗りつぶしのボタン）
  - フォロー済み：[フォロー中]（枠線のボタン）。マウスを乗せると [フォロー解除] の表示に変わる
- 押すと、未フォロー → フォロー、フォロー済み → 解除（トグル）
- 画面遷移なしでボタンの表示を変え、プロフィールではフォロワー数も更新する。応答が失敗したら元に戻す
- サーバーの処理は「フォローする」「解除する」の 2 つの操作に分け、同じ操作を 2 回受けても結果が変わらないようにする
- 自分自身にはボタンを表示しない。API に直接要求された場合もサーバー側で 400 にする
- 相手が自分をフォローしている場合は、名前の近くに「フォローされています」と表示する（プロフィール・検索結果）

### F-20 フォロー数・フォロワー数表示

- フォロー数 = そのユーザーがフォローしている人数、フォロワー数 = そのユーザーをフォローしている人数
- プロフィール（SC-05）に「12 フォロー中　34 フォロワー」の形式で表示する（一覧画面へのリンクは無し）
- 自分がフォロー / 解除したときは、相手のプロフィールのフォロワー数をすぐに ±1 する

## 5. 入力制約

入力項目なし。

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |
| --- | --- |
| 画面 | SC-05 プロフィール画面、SC-07 ユーザー検索画面（ボタン）。SC-03・SC-04（プロフィールへの導線） |
| API（案） | `POST /api/users/{username}/follow`（フォローする）、`DELETE /api/users/{username}/follow`（解除する）。応答に相手の最新のフォロワー数を含める |
| テーブル | follows, users |

## 7. 権限

| 操作 | 未ログイン | ログイン中（他人） | ログイン中（自分） |
| --- | --- | --- | --- |
| フォロー / 解除 | × | ○ | ×（400） |
| フォロー数・フォロワー数の閲覧 | × | ○ | ○ |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| 通信に失敗した | ボタンとフォロワー数を押す前の状態に戻し、「フォローできませんでした。」を短く表示する |
| 相手のユーザーが存在しない（退会など） | 「このユーザーは存在しません。」 |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| 2.1 経路 1 | SC-07 で他人の @ユーザー名を検索し、結果の行の [フォローする] を押す | その場で [フォロー中] に変わる。タイムラインの「フォロー中」タブにその人の投稿が出る |
| 2.1 経路 2 | タイムラインで他人の投稿の表示名をクリックし、開いたプロフィールで [フォローする] を押す | [フォロー中] に変わり、フォロワー数が +1 される |
| 2.1 経路 2 | 投稿詳細で、コメントした人の @ユーザー名をクリックする | その人のプロフィールが開き、[フォローする] でフォローできる |
| 2.1 経路 2 | 投稿カードの本文（名前以外）をクリックする | 投稿詳細が開く（プロフィールには移らない） |
| 2.1 | 自分の名前をクリックする | 自分のプロフィールが開き、フォローボタンの代わりに [プロフィールを編集] が出る |
| F-19 | フォロー済みの [フォロー中] を押す | 確認なしで解除され、[フォローする] に戻る。フォロワー数が -1 される |
| F-19 | 自分自身をフォローする API を直接呼ぶ | 400 が返り、follows に行が増えない |
| F-19 | 同じ相手の「フォローする」API を 2 回続けて呼ぶ | エラーにならず、follows の行は 1 行だけ |
| F-19 | 相手からフォローされている状態で相手のプロフィールを開く | 「フォローされています」が表示される |
| F-20 | 3 人をフォローし、2 人にフォローされているユーザーのプロフィールを開く | 「3 フォロー中　2 フォロワー」と表示される |
