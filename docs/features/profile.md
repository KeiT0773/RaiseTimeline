## 2. 概要

ユーザーごとのページ（プロフィール）を表示し、自分のアイコン・表示名・自己紹介を編集する機能。他人のプロフィールはフォローする場所にもなる（[follow.md](follow.md) 2.1）。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-16 | プロフィール表示 | SC-05 |
| F-18 | プロフィール編集 | SC-06 |

## 3. 業務ルール

- プロフィールは、ログイン中の利用者なら誰のものでも見られる。
- 編集できるのは本人だけ。編集できるのはアイコン・表示名・自己紹介だけで、ユーザー名（@ID）・メールアドレスは変更できない。
- アイコンは任意。未設定のときは、表示名の先頭 1 文字を、ユーザーごとに決まる背景色の丸の中に表示する（頭文字アイコン）。背景色はユーザー ID から決め、表示名を変えても変わらない。
- アイコンはどの画面でも丸く表示する。表示する場所と大きさは次のとおり。

| 場所 | 大きさ（目安） |
| --- | --- |
| 共通ヘッダーの自分の名前の左 | 28px |
| タイムライン・プロフィールの投稿一覧の投稿の左 | 40px |
| 投稿詳細の投稿者 | 48px |
| コメントの左 | 32px |
| ユーザー検索の結果・おすすめユーザーの行の左 | 40px |
| プロフィールの上部 | 96px |
| プロフィール編集のプレビュー | 96px |

- 投稿・コメント・検索結果のアイコンは、名前と同じくクリックするとそのユーザーのプロフィールへ移る。
- ヘッダー画像（プロフィール上部の横長の画像）は扱わない。

## 4. 機能詳細

### F-16 プロフィール表示

- URL：`/users/:username`（例：`/users/hanako`）。ユーザー名の大文字と小文字は区別しない
- 開き方：タイムライン・投稿詳細・プロフィールの投稿一覧で表示名・@ユーザー名・アイコンをクリックする、ユーザー検索の結果の行をクリックする、共通ヘッダーの自分の名前をクリックする（自分のプロフィール）
- 表示項目
  - アイコン（未設定なら頭文字アイコン）
  - 表示名、@ユーザー名、自己紹介（改行を反映、HTML はエスケープ。未設定なら行ごと出さない）
  - 登録日（「2026年11月から利用しています」の形式）
  - 投稿数、フォロー数、フォロワー数（[follow.md](follow.md) F-20）
  - 相手が自分をフォローしているときは「フォローされています」
  - 他人のプロフィール：[フォローする] / [フォロー中]（[follow.md](follow.md) F-19）
  - 自分のプロフィール：[プロフィールを編集]（SC-06 へ）
- 下部に、そのユーザーの投稿一覧をタイムラインと同じ形式（いいね・コメント数・削除・画像の動作も同じ）・新しい順・20 件ずつ（[さらに読み込む]）で表示する
- 投稿が 0 件のときは「まだ投稿がありません」と表示する
- 存在しないユーザー名のときは「このユーザーは存在しません」と表示する（API は 404）

### F-18 プロフィール編集

- URL：`/settings/profile`。自分のプロフィールの [プロフィールを編集] から開く
- 入力：アイコン、表示名、自己紹介（残り文字数を表示）
- 現在の値を初期値として表示する。ユーザー名（@ID）は「変更できません」と添えて表示だけする
- アイコン
  - 現在のアイコン（未設定なら頭文字アイコン）をプレビューとして表示する
  - [画像を選択] でファイルを 1 枚選ぶと、プレビューが選んだ画像に変わる（この時点では保存しない）。正方形でない画像は中央を正方形に切り抜いた見た目で表示する
  - アイコンが設定されているとき（選び直した画像を含む）は [アイコンを削除] を表示する。押すとプレビューが頭文字アイコンに戻る（この時点では保存しない）
  - 形式・サイズが制約（5.）に合わないファイルを選んだときは、プレビューを変えずにアイコン欄の下にエラーを表示する
  - アイコンの変更・削除は、表示名・自己紹介と一緒に [保存する] で確定する。[キャンセル] では反映しない
- 保存（サーバー）
  - 送信は `multipart/form-data`。サーバー側でも形式・サイズを検証し直す
  - 形式はファイルの中身で判定し、EXIF を取り除き、中央を正方形に切り抜いて 400×400px に縮小し、ランダムなファイル名でストレージに保存する（投稿画像と同じ扱い。[post.md](post.md) F-17）
  - アイコンを変更・削除したときは、前のアイコンのファイルをストレージから削除する
  - アイコンの保存に失敗したら、表示名・自己紹介も保存しない
- [保存する] に成功したら自分のプロフィール（SC-05）へ移り、「プロフィールを更新しました」と表示する
- 入力エラーのときは入力内容を残したまま、該当項目の下にエラーを表示する
- [キャンセル] / ← 戻る は保存せずに自分のプロフィールへ戻る
- 更新の対象は常にログイン中の利用者自身にする（URL や送信内容にユーザー ID を持たせない。他人のプロフィールを書き換える手段を作らない）
- 自己紹介を空にして保存したら「未設定」（NULL）として扱う

## 5. 入力制約

| 項目 | 制約 | エラーの文言（例） |
| --- | --- | --- |
| 表示名 | 必須、1〜30 文字（前後の空白を除いて判定。空白のみは不可） | 「表示名を入力してください」「表示名は 30 文字以内にしてください」 |
| 自己紹介 | 任意、0〜160 文字。改行可 | 「自己紹介は 160 文字以内にしてください」 |
| アイコンの形式 | JPEG / PNG / GIF（静止画として表示）/ WebP | 「JPEG・PNG・GIF・WebP の画像を選択してください」 |
| アイコンのサイズ | 5MB 以下 | 「5MB 以下の画像を選択してください」 |

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |
| --- | --- |
| 画面 | SC-05 プロフィール画面、SC-06 プロフィール編集画面 |
| API（案） | `GET /api/users/{username}`（プロフィールと件数・フォロー状態）、`GET /api/users/{username}/posts?before=<投稿 ID>`（投稿一覧）、`PATCH /api/me/profile`（自分のプロフィールの更新。アイコンを含むため `multipart/form-data`。アイコンを削除するときは削除を示す項目を送る） |
| ストレージ | アイコン画像（投稿画像と同じ保存先。本番は S3、開発時は `backend/storage/`） |
| テーブル | users, posts, follows |

## 7. 権限

| 操作 | 未ログイン | ログイン中（他人） | ログイン中（自分） |
| --- | --- | --- | --- |
| プロフィールの閲覧 | × | ○ | ○ |
| プロフィールの編集 | × | ×（手段が無い） | ○ |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| プロフィールの取得に失敗した | 「プロフィールを読み込めませんでした。」と [再読み込み] |
| 保存に失敗した | フォームの上に「保存できませんでした。」。入力内容は消さない |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| F-16 | 他人のプロフィールを開く | アイコン・表示名・@ユーザー名・自己紹介・登録日・投稿数・フォロー数・フォロワー数と [フォローする] / [フォロー中] が表示される |
| F-16 | 自分のプロフィールを開く | フォローボタンの代わりに [プロフィールを編集] が表示される |
| F-16 | 投稿が 25 件あるユーザーのプロフィールを開き、[さらに読み込む] を押す | 20 件 → 25 件と表示され、[さらに読み込む] が消える |
| F-16 | `/users/HANAKO` を開く（登録名は `hanako`） | hanako のプロフィールが表示される |
| F-16 | 存在しないユーザー名の URL を開く | 「このユーザーは存在しません」が表示される |
| F-18 | 表示名と自己紹介を変えて保存する | 自分のプロフィールに移り、変更後の内容と「プロフィールを更新しました」が表示される。タイムラインの自分の投稿の表示名も変わっている |
| F-18 | 表示名を空にして保存する | 保存されず、表示名の下にエラーが表示される。入力した自己紹介は残っている |
| F-18 | 自己紹介を 161 文字にする | 残り文字数が赤字になり [保存する] が押せない |
| F-18 | 自己紹介に `<b>太字</b>` と入力して保存する | プロフィールにタグが文字のまま表示される |
| F-16 | アイコンが未設定のユーザーのプロフィール・投稿を見る | 表示名の頭文字が丸の中に表示される。同じユーザーはどの画面でも同じ背景色になる |
| F-18 | 横長の画像をアイコンに選んで保存する | プレビューと保存後のアイコンが、中央を正方形に切り抜いた丸で表示される。プロフィール・自分の投稿・コメント・共通ヘッダーのアイコンが変わっている |
| F-18 | アイコンを選んだあと [キャンセル] を押す | アイコンは変わっていない |
| F-18 | 設定済みのアイコンを [アイコンを削除] して保存する | 頭文字アイコンに戻る。前のアイコンのファイルがストレージから消えている |
| F-18 | テキストファイル・6MB の画像をアイコンに選ぶ | プレビューは変わらず、アイコン欄の下に形式・サイズのエラーが表示される |
