## 2. 概要

投稿の ♡ ボタンでいいねを付けたり外したりし、自分がいいね済みかを表示する機能。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-14 | いいね / 取り消し | SC-03, SC-04, SC-05 |
| F-15 | 自分のいいね状態表示 | SC-03, SC-04, SC-05 |

## 3. 業務ルール

- いいねできるのはログイン中の利用者だけ。自分の投稿にもいいねできる。
- いいねは 1 ユーザーにつき 1 投稿 1 回まで。もう一度押すと取り消し（トグル）。
- 重複は画面・サーバー・DB の一意制約（`user_id` + `post_id`）の 3 段で防ぐ。
- 誰がいいねしたかの一覧は表示しない（件数だけ）。

## 4. 機能詳細

### F-14 いいね / 取り消し

- ♡ を押すと、未いいね → いいね、いいね済み → 取り消し
- 画面遷移なしで、件数と色をすぐに更新する（押した時点で画面を先に変え、サーバーの応答が失敗したら元に戻す）
- サーバーの処理は「いいねを付ける」「いいねを外す」の 2 つの操作に分け、同じ操作を 2 回受けても結果が変わらないようにする（既にいいね済みの投稿に「付ける」が届いてもエラーにせず、件数も増やさない）
- 連打されたときは、最後に押した状態になるようにする（応答を待つ間はボタンを無効にする）

### F-15 自分のいいね状態表示

- 自分がいいね済みの投稿は、ハートを塗りつぶし（♥、色付き）で表示する。未いいねは枠線（♡）
- タイムライン・投稿詳細・プロフィールのどの画面でも同じ表示にする
- ボタンには状態が分かるラベルを付ける（`aria-pressed`、「いいね」「いいねを取り消す」）

## 5. 入力制約

入力項目なし。

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |
| --- | --- |
| 画面 | SC-03 タイムライン画面、SC-04 投稿詳細画面、SC-05 プロフィール画面（投稿一覧） |
| API（案） | `POST /api/posts/{id}/like`（付ける）、`DELETE /api/posts/{id}/like`（外す）。応答に最新のいいね数を含める |
| テーブル | likes |

## 7. 権限

| 操作 | 未ログイン | ログイン中 |
| --- | --- | --- |
| いいね / 取り消し | × | ○（自分の投稿も可） |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| 通信に失敗した | ハートと件数を押す前の状態に戻し、「いいねできませんでした。」を短く表示する |
| 投稿が削除されていた | 「この投稿は削除されました。」を表示し、一覧から消す |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| F-14 | 未いいねの投稿の ♡ を押す | 画面遷移せずにハートが塗りつぶされ、件数が +1 される。再読み込みしても維持される |
| F-14 | いいね済みの投稿の ♥ を押す | 塗りつぶしが外れ、件数が -1 される |
| F-14 | 「付ける」API を同じ投稿に 2 回続けて呼ぶ | エラーにならず、likes の行は 1 行だけ。件数は 1 だけ増える |
| F-14 | 通信を切った状態で ♡ を押す | ハートと件数が元に戻り、失敗が表示される |
| F-15 | いいね済みの投稿をタイムライン・投稿詳細・プロフィールで表示する | どの画面でも塗りつぶしで表示される |
| F-15 | 別のユーザーでログインし直して同じ投稿を見る | そのユーザーがいいねしていなければ枠線で表示される |
