## 2. 概要

テキスト（280 文字まで）と画像（4 枚まで）を投稿し、1 件の投稿を詳しく表示し、自分の投稿を削除する機能。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-08 | 投稿作成 | SC-03 |
| F-09 | 投稿詳細表示 | SC-04 |
| F-10 | 投稿削除 | SC-03, SC-04, SC-05 |
| F-17 | 画像添付・表示 | SC-03〜SC-05、画像ビューアー |

## 3. 業務ルール

- 投稿できるのはログイン中の利用者だけ。投稿者は常にログイン中の利用者自身（他人として投稿できない）。
- 本文か画像の **どちらか一方があれば投稿できる**（画像のみの投稿も可）。
- 投稿の編集はできない（削除だけ）。投稿後の画像の追加・差し替え・個別削除もできない。
- 投稿を削除できるのは投稿者本人だけ。削除すると、その投稿のコメント・いいね・画像（DB の行とファイルの両方）も消える。
- 画像はファイルとしてストレージ（本番は S3、開発時はディスク）に保存し、DB には保存先のパスだけを持つ。

## 4. 機能詳細

### F-08 投稿作成

- タイムライン（SC-03）上部の投稿フォームから投稿する
- 残り文字数をリアルタイムで表示する（280 → 0。超過したら赤字にして [投稿] を無効にする）
- 本文が空（空白だけを含む）で画像も無いときは [投稿] を無効にする
- 画像だけが添付されているときは、本文が空でも投稿できる（本文は空文字で保存する）
- 送信中は [投稿] を無効にし、二重に投稿されないようにする
- 投稿に成功したら、フォームを空にし、現在のタブの先頭に自分の投稿を表示する

### F-09 投稿詳細表示

- URL：`/posts/:id`
- 表示項目：アイコン、表示名、@ユーザー名、本文、添付画像（元の縦横比）、投稿日時（絶対表示 `YYYY/MM/DD HH:mm`）、💬 コメント数、♡ いいね数、（自分の投稿なら）[削除]
- 下部にコメントフォームとコメント一覧を表示する（[comment.md](comment.md)）
- 投稿者・コメントした人の表示名・@ユーザー名をクリックすると、その人のプロフィール（SC-05）へ移る（[follow.md](follow.md) 2.1 経路 2）
- 存在しない（削除済みを含む）投稿の場合は「この投稿は存在しないか、削除されました」と表示する

### F-10 投稿削除

- 自分の投稿にだけ [削除] を表示する
- 押すと確認ダイアログ「この投稿を削除しますか？」を出し、OK のときだけ削除する
- 削除後：タイムライン・プロフィールでは一覧からその投稿を消す。投稿詳細ではタイムライン（SC-03）へ移る。どちらも「投稿を削除しました」と表示する
- サーバー側でも投稿者本人かを確かめる（他人の投稿の削除要求には 403 を返す。画面でボタンを隠すだけにしない）
- 削除と同時に、ストレージ上の画像ファイル（元画像とサムネイル）も削除する

### F-17 画像添付・表示

**添付（投稿フォーム）**

- 投稿フォームの 🖼 ボタンからファイルを選ぶ（複数選択可）。最大 4 枚
- 選んだ画像はフォームの中にサムネイルでプレビュー表示し、各サムネイルの [×] で添付を取り消せる
- 4 枚添付済みのときは 🖼 ボタンを無効にする
- 枚数・形式・サイズの制約（5.）に合わないファイルは添付せず、フォームの下にエラーを表示する
- 添付した順が表示順になる
- 送信は `multipart/form-data`。サーバー側でも枚数・形式・サイズを必ず検証し直す（画面のチェックだけにしない）

**保存（サーバー）**

- 形式は拡張子ではなくファイルの中身（先頭のバイト列）で判定する
- 位置情報などの EXIF を取り除いてから保存する
- 保存するファイル名はランダムな名前に付け替える（元のファイル名は使わない）
- タイムライン用の縮小版（サムネイル）を保存時に作る
- 画像の保存に失敗したら投稿自体も保存しない（投稿だけが残らないようにする）

**表示**

- 本文の下に表示する。枚数に応じて並べ方を変える（1 枚：全幅 / 2 枚：左右 2 分割 / 3 枚：左 1 枚＋右 2 枚 / 4 枚：2×2）
- タイムライン・プロフィールでは縦横比をそろえて切り抜いたサムネイルを、投稿詳細では元の縦横比で表示する
- 画像は遅延読み込み（`loading="lazy"`）する
- 画像をクリックすると画像ビューアー（モーダル）で拡大表示する。複数枚あるときは ← → で切り替え、Esc・背景クリック・[×] で閉じる
- 画像のクリックは投稿詳細への移動より優先する（画像以外の本文部分をクリックすると SC-04 へ）
- `alt` 属性は「{表示名}さんの投稿画像 1/3」の形式にする
- GIF は静止画（1 フレーム目）として表示する

## 5. 入力制約

| 項目 | 制約 | エラーの文言（例） |
| --- | --- | --- |
| 本文 | 0〜280 文字（改行を含めて数える）。画像が無いときは必須で、空白のみは不可 | 「本文を入力するか、画像を添付してください」「本文は 280 文字以内にしてください」 |
| 画像の枚数 | 0〜4 枚 | 「画像は 4 枚まで添付できます」 |
| 画像の形式 | JPEG / PNG / GIF / WebP | 「JPEG・PNG・GIF・WebP の画像を選択してください」 |
| 画像のサイズ | 1 枚あたり 5MB 以下 | 「5MB 以下の画像を選択してください」 |

文字数は「見た目の 1 文字」ではなく Unicode のコードポイント単位で数える（絵文字も原則 1 文字。画面とサーバーで同じ数え方にする）。

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |

| 画面 | SC-03 タイムライン画面（投稿フォーム）、SC-04 投稿詳細画面、SC-05 プロフィール画面（投稿一覧）、画像ビューアー |

## 7. 権限

| 操作 | 未ログイン | ログイン中（他人の投稿） | ログイン中（自分の投稿） |
| --- | --- | --- | --- |
| 投稿作成 | × | — | ○ |
| 投稿詳細の閲覧 | × | ○ | ○ |
| 投稿削除 | × | ×（403） | ○ |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| 投稿の送信に失敗した | フォームの下に「投稿できませんでした。時間をおいてもう一度お試しください。」。入力した本文と添付した画像は消さない |
| 削除に失敗した | 「削除できませんでした。」。投稿は一覧に残す |
| 既に削除された投稿を削除しようとした | 「この投稿は既に削除されています。」を表示し、一覧から消す |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| F-08 | 280 文字ちょうど、281 文字の本文をそれぞれ入力する | 280 文字は投稿でき、281 文字では残り文字数が赤字になり [投稿] が押せない |
| F-08 | 本文を空白だけにし、画像も付けない | [投稿] が押せない。API に直接送っても 400 で投稿されない |
| F-08 | 画像だけを 1 枚付けて投稿する | 投稿され、タイムラインに本文の行が無い画像だけの投稿が表示される |
| F-08 | [投稿] を素早く 2 回押す | 投稿は 1 件だけ作られる |
| F-09 | 投稿詳細を開く | 日時が `YYYY/MM/DD HH:mm` で表示され、画像が元の縦横比で表示される |
| F-09 | 投稿詳細でコメントした人の名前をクリックする | その人のプロフィールが開く |
| F-10 | 自分の投稿の [削除] を押し、確認ダイアログでキャンセルする | 削除されない |
| F-10 | 自分の投稿を削除する | 投稿が消え、その投稿のコメント・いいね・画像の行が DB から消え、画像ファイルもストレージから消える |
| F-10 | 他人の投稿の削除 API を直接呼ぶ | 403 が返り、削除されない |
| F-17 | 画像を 5 枚選ぶ | 4 枚だけ添付され、「画像は 4 枚まで添付できます」が表示される |
| F-17 | 拡張子を `.jpg` に変えたテキストファイルを選ぶ | 画面またはサーバーで弾かれ、保存されない |
| F-17 | 6MB の画像を選ぶ | 添付されず、「5MB 以下の画像を選択してください」が表示される |
| F-17 | 位置情報（GPS）の入った JPEG を投稿し、保存されたファイルを確認する | EXIF の位置情報が残っていない。ファイル名が元の名前ではない |
| F-17 | 1〜4 枚の投稿をそれぞれ表示する | 枚数に応じた並べ方になる |
| F-17 | タイムラインの画像をクリックし、← → と Esc を押す | 拡大表示され、画像が切り替わり、Esc で閉じる。投稿詳細には移らない |
