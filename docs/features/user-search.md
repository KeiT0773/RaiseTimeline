## 2. 概要

フォローする相手を探すための機能。@ユーザー名や表示名で他のユーザーを探し、結果の画面からそのままフォローできる。検索語が無いときは、おすすめのユーザーを表示する。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-22 | ユーザー検索 | SC-07 |
| F-23 | おすすめユーザー | SC-07 |

### 2.1 フォローする相手の見つけ方の中での位置づけ

フォローする相手を見つける経路は、(1) ユーザー検索から、(2) 投稿・コメントの名前をクリックしてプロフィールから、の 2 つ（[follow.md](follow.md) 2.1）。本書は (1) を定める。(2) は [timeline.md](timeline.md)・[post.md](post.md)・[comment.md](comment.md)・[profile.md](profile.md) に定める。

## 3. 業務ルール

- 検索できるのはログイン中の利用者だけ。
- 検索の対象は **ユーザーだけ**（@ユーザー名と表示名）。投稿本文・ハッシュタグの検索は行わない（要件定義書 3.2）。
- 検索の対象から外すユーザーは無い（自分も結果に出る。ただし自分の行にはフォローボタンを出さない）。
- 検索語は保存しない（検索履歴は作らない）。

## 4. 機能詳細

### F-22 ユーザー検索

**画面と開き方**

- URL：`/search?q=<検索語>`。検索語は URL に残すため、再読み込み・ブラウザの戻る・URL の共有で同じ結果に戻れる
- 開き方：共通ヘッダーの「🔍 ユーザーを探す」、タイムラインの「フォロー中」が 0 件のときの [ユーザーを探す]（[timeline.md](timeline.md) F-21）

**検索のしかた**

- 画面上部の検索欄に入力し、Enter または [検索] で実行する（入力中に逐次検索はしない）
- 検索語の前後の空白は取り除く。先頭の `@` も取り除く（`@hanako` と `hanako` は同じ結果）
- **@ユーザー名と表示名の両方を対象に、部分一致** で探す。大文字と小文字は区別しない
  - 例：`han` → `@hanako`、`@Hana_dev` が見つかる。`花子` → 表示名が「佐藤花子」のユーザーが見つかる
- 検索語に含まれる `%`・`_`・`\` は、ワイルドカードではなく文字として扱う（エスケープする）

**結果の並び順**

1. @ユーザー名が検索語と完全に一致するユーザー
2. @ユーザー名が検索語で始まるユーザー
3. それ以外（@ユーザー名か表示名のどこかに検索語を含むユーザー）

同じ順位の中は、フォロワーの多い順 → 登録の新しい順。

**結果の表示**

- 各行：アイコン（[profile.md](profile.md) 3.）、表示名、@ユーザー名、自己紹介の 1 行目（長い場合は末尾を「…」で省略）、「フォローされています」（相手が自分をフォローしているとき）、[フォローする] / [フォロー中]（[follow.md](follow.md) F-19 と同じ動き。自分の行には出さない）
- 行（ボタン以外）をクリックすると、そのユーザーのプロフィール（SC-05）へ移る
- 20 件ずつ表示し、[さらに読み込む] で次の 20 件を足す。タイムライン（[timeline.md](timeline.md) F-06）と違い、並び順が投稿日時ではないため、ページ番号（`page`）で次の 20 件を取る
- 0 件のときは「「{検索語}」に一致するユーザーは見つかりませんでした」と表示する

### F-23 おすすめユーザー

- 検索欄が空の状態で SC-07 を開いたとき、検索結果の代わりに「おすすめユーザー」を表示する
- 対象：自分以外で、まだフォローしていないユーザー
- 並び順：フォロワーの多い順 → 登録の新しい順。最大 10 件（ページングなし）
- 各行の表示と動作は F-22 の結果と同じ（[フォローする] でその場でフォローできる）
- フォローしたユーザーは、画面を開き直すまでは一覧に残す（ボタンが [フォロー中] になる）。開き直すと一覧から外れる
- 対象が 0 人のとき（全員をフォロー済みなど）は「おすすめできるユーザーはいません」と表示する

## 5. 入力制約

| 項目 | 制約 | 制約に合わないとき |
| --- | --- | --- |
| 検索語 | 前後の空白と先頭の `@` を除いて 1〜50 文字 | 空なら検索せずおすすめユーザーを表示する。51 文字以上は入力欄で入力できないようにする（`maxLength`）。API に直接送られた場合は 400 |

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |
| --- | --- |
| 画面 | SC-07 ユーザー検索画面、共通ヘッダー（導線）、SC-03（「フォロー中」0 件時の導線） |
| API（案） | `GET /api/users/search?q=<検索語>&page=<n>`（20 件。各ユーザーにフォロー済みか・フォローされているかを含める）、`GET /api/users/recommended`（最大 10 件） |

## 7. 権限

| 操作 | 未ログイン | ログイン中 |
| --- | --- | --- |
| ユーザー検索・おすすめの閲覧 | × | ○ |
| 結果からのフォロー | × | ○（自分以外） |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| 検索に失敗した（サーバー停止・通信断） | 結果の位置に「検索できませんでした。」と [もう一度検索] |
| フォローに失敗した | [follow.md](follow.md) 8. と同じ |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| F-22 | 共通ヘッダーの「🔍 ユーザーを探す」を押す | SC-07 が開き、検索欄が空でおすすめユーザーが表示される |
| F-22 | `@hanako` と `hanako` でそれぞれ検索する | 同じ結果になり、`hanako` が先頭に出る |
| F-22 | `HANA` で検索する | `hanako`・`Hana_dev` など、大文字と小文字に関係なく一致するユーザーが出る |
| F-22 | 表示名の一部（例：`花子`）で検索する | 表示名に「花子」を含むユーザーが出る |
| F-22 | `han` で検索する（`han`、`hanako`、`ihan` がいる） | `han` → `hanako` → `ihan` の順に並ぶ |
| F-22 | `%` や `_` だけで検索する | 全員が出るのではなく、ユーザー名・表示名にその文字を含むユーザーだけが出る（いなければ 0 件の文言） |
| F-22 | 結果の行の [フォローする] を押す | 画面遷移せず [フォロー中] に変わる |
| F-22 | 結果の行（ボタン以外）をクリックする | そのユーザーのプロフィールが開く |
| F-22 | 自分のユーザー名で検索する | 自分が結果に出るが、フォローボタンは出ない |
| F-22 | 検索した後に再読み込みする | URL の `q` から同じ検索結果が表示される |
| F-22 | 一致するユーザーがいない語で検索する | 「「{検索語}」に一致するユーザーは見つかりませんでした」と表示される |
| F-22 | 一致するユーザーが 25 人いる語で検索し、[さらに読み込む] を押す | 20 人 → 25 人と表示され、重複が無い |
| F-23 | 検索欄が空の状態で開く | 自分とフォロー済みのユーザーを除いたユーザーが、フォロワーの多い順に最大 10 人表示される |
| F-23 | おすすめの行で [フォローする] を押してから画面を開き直す | フォローしたユーザーがおすすめから外れている |
