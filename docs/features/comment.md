## 2. 概要

投稿詳細画面（SC-04）で、投稿にコメントを付け、コメントの一覧を見て、自分のコメントを削除する機能。

| ID | 機能名 | 画面 |
| --- | --- | --- |
| F-11 | コメント作成 | SC-04 |
| F-12 | コメント一覧表示 | SC-04 |
| F-13 | コメント削除 | SC-04 |

## 3. 業務ルール

- コメントできるのはログイン中の利用者だけ。他人の投稿にも自分の投稿にもコメントできる。
- コメントはテキストのみ（画像は付けられない）。コメントへの返信（入れ子）・コメントへのいいね・編集はできない。
- コメントを削除できるのはコメントした本人だけ（投稿者でも他人のコメントは消せない）。
- 投稿が削除されると、その投稿のコメントもすべて消える。

## 4. 機能詳細

### F-11 コメント作成

- 投稿詳細画面の投稿の下にコメントフォームを置く
- 残り文字数をリアルタイムで表示する（280 → 0。超過したら赤字にして [コメント] を無効にする）。空（空白のみ）のときも [コメント] を無効にする
- 送信中は [コメント] を無効にし、二重に送信されないようにする
- 成功したら、フォームを空にし、一覧の末尾に自分のコメントを追加し、投稿のコメント数を +1 する

### F-12 コメント一覧表示

- 表示項目：表示名、@ユーザー名、日時（相対表示）、本文（改行を反映、HTML はエスケープ）、（自分のコメントなら）[削除]
- 並び順：古い順（会話の流れどおり）
- 表示名・@ユーザー名をクリックすると、そのユーザーのプロフィール（SC-05）へ移る（[follow.md](follow.md) 2.1 経路 2）
- 0 件のときは「まだコメントはありません」と表示する
- コメントはページングせず全件表示する（1 投稿あたりのコメント数は多くならない想定。増えた場合は将来 20 件ずつにする）

### F-13 コメント削除

- 自分のコメントにだけ [削除] を表示する
- 押すと確認ダイアログ「このコメントを削除しますか？」を出し、OK のときだけ削除する
- 削除後は一覧から消し、投稿のコメント数を -1 する
- サーバー側でもコメントした本人かを確かめる（他人のコメントの削除要求には 403）

## 5. 入力制約

| 項目 | 制約 | エラーの文言（例） |
| --- | --- | --- |
| コメント本文 | 必須、1〜280 文字（空白のみは不可。数え方は [post.md](post.md) 5. と同じ） | 「コメントを入力してください」「コメントは 280 文字以内にしてください」 |

## 6. 関連する画面・API・テーブル

| 種別 | 対象 |
| --- | --- |
| 画面 | SC-04 投稿詳細画面 |
| API（案） | `GET /api/posts/{id}/comments`、`POST /api/posts/{id}/comments`、`DELETE /api/comments/{id}` |
| テーブル | comments, users, posts |

## 7. 権限

| 操作 | 未ログイン | ログイン中（他人のコメント） | ログイン中（自分のコメント） |
| --- | --- | --- | --- |
| コメント作成 | × | — | ○ |
| コメント閲覧 | × | ○ | ○ |
| コメント削除 | × | ×（403） | ○ |

## 8. エラーと表示

| 状況 | 表示 |
| --- | --- |
| 送信に失敗した | フォームの下に「コメントできませんでした。」。入力した本文は消さない |
| コメント先の投稿が削除されていた | 「この投稿は削除されました。」を表示し、タイムラインへ移る |
| 削除に失敗した | 「削除できませんでした。」。コメントは一覧に残す |

## 9. 受け入れ基準

| 対象 | 確認方法 | 合格条件 |
| --- | --- | --- |
| F-11 | 他人の投稿にコメントする | 一覧の末尾に追加され、コメント数が +1 される。タイムラインに戻っても件数が増えている |
| F-11 | 281 文字・空白だけのコメントを入力する | [コメント] が押せない。API に直接送っても 400 で保存されない |
| F-12 | 3 人が順にコメントした投稿を開く | コメントが古い順に並ぶ。自分のコメントにだけ [削除] がある |
| F-12 | コメントした人の名前をクリックする | その人のプロフィールが開き、[フォローする] が表示される（自分以外の場合） |
| F-13 | 自分のコメントを削除する | 確認ダイアログの OK 後に一覧から消え、コメント数が -1 される |
| F-13 | 自分の投稿に付いた他人のコメントの削除 API を直接呼ぶ | 403 が返り、削除されない |
